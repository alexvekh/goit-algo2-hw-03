# 📦 Логістика та Продуктивність Структур Даних

Цей репозиторій містить два окремі проєкти:

- Алгоритм Едмондса-Карпа для обчислення максимального потоку в логістичній мережі.
- Порівняння продуктивності OOBTree та dict для зберігання товарів і виконання діапазонних запитів за ціною.

## 🧮 Проєкт 1: Максимальний потік у логістичній мережі
- graph.py - побудова візуального відображеня графу
- edmond_karp.py - Реалізує алгоритм Едмондса-Карпа для знаходження максимального потоку.
- report.pdf - Звіт з розрахунками та поясненнями (відповіді на питання)

✅ Висновки описано у файлі report.pd

## 📊 Проєкт 2: OOBTree vs Dict — Порівняння діапазонних запитів
- generated_items_data.csv - Згенерований набір даних про 10 000 товарів.

    Формат CSV з колонками:

    - ID — унікальний ідентифікатор товару.
    - Name — назва.
    - Category — категорія.
    - Price — ціна товару (float).
- b-tree_vs_dict.py - Завантажує дані з CSV та зберігає їх у двох структурах:
    - OOBTree (з бібліотеки BTrees.OOBTree)
    - dict
      
    Генерує 100 випадкових діапазонів цін та вимірює час виконання для порівняння

✅ *Висновок:* - OOBTree демонструє вищу ефективність при виконанні діапазонних запитів завдяки своїй структурі B-дерева.

    Total range_query time for OOBTree: 0.000902 seconds
    Total range_query time for Dict: 1.051120 seconds
